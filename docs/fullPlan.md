# 国庆假期旅行计划

## 整体信息概览
- **目的地:** 济南, 淄博, 青岛
- **旅行时间:** 10月4日 - 10月8日
- **核心活动:** 泉城探访, 淄博美食与文化, 青岛海滨风情

## 详细行程

### 10月4日 (周三)

#### 上午
- **项目类型:** 出发
- **目的地:** 济南西
- **事项:**
    - **交通:** 南通 -> 济南西, G2586次列车, 08:28 - 12:34
    - **票价:** 375元/人
    - **备注:** 3号晚上返回东城，4号预约顺风车从东城前往南通站。

#### 下午
- **项目类型:** 景点, 干饭
- **目的地:** 济南
- **事项:**
    - **交通:** 济南西 -> 你好酒店 (约19公里)
    - **餐饮:**
        - **餐厅:** 陈氏肥蛤（圣凯财富广场店）
        - **备注:** 提前打电话确认，若人多则点外卖或更换餐厅。
    - **黑虎泉:**
        - **开放时间:** 全天开放
        - **门票:** 免费
        - **游玩线路:** 导航至解放阁入口，沿途经过九女泉 -> 白石泉 (可打水) -> 玛瑙泉 -> 黑虎泉。
        - **护城河游船:**
            - **时间:** 09:00 - 17:00
            - **路线:** 黑虎泉 -> 大明湖西, 50元/人
            - **购票:** 微信小程序“天下第一泉”购买，只能购买当天票。上午班次08:00开始预约，下午班次11:00开始预约 (放票时间可能因水位调整)。建议购买16:00班次。
            - **选座建议:** 手机购票最佳位置1、2号，其次是1、2号后面。
    - **大明湖:**
        - **开放时间:** 06:00 - 22:00
        - **活动:** 打卡夏雨荷（还珠格格），在大明湖拍摄夕阳。
    - **超然楼:**
        - **开放时间:** 08:00 - 21:30
        - **门票:** 免费上楼，每晚18:40亮灯，观赏亮灯即可。
        - **拍照机位1:** 搜索“南丰祠新区游船码头”，可拍摄南丰桥与超然楼同框。
        - **拍照机位2:** 搜索“尚泉尚水茶馆”，其前面平台可拍摄湖面与楼阁全景。

### 10月5日 (周四)

#### 上午
- **项目类型:** 景点
- **目的地:** 济南
- **事项:**
    - **交通:** 你好酒店 -> 趵突泉 (约2.5公里)
    - **趵突泉:**
        - **开放时间:** 07:00 - 20:00
        - **门票:** 40元/人 (抖音购票37元/人)
        - **免费入园时间:** 05:00 - 06:30 和 18:00 - 22:30
        - **游玩线路:** 南门 -> 趵突泉泉眼 -> 漱玉泉 -> 李清照纪念馆 -> 观澜亭 -> 万竹园 -> 北门
        - **备注:** 8点前到人少一点，南门进北门出
    - **五龙潭:**
        - **开放时间:** 07:00 - 22:00
        - **门票:** 免费
        - **游玩线路:** 南门 -> 五龙壁 -> 天镜泉 -> 玉泉 -> 月牙泉 -> 美铭广场 -> 邓恩铭塑像 -> 假山机位 -> 五龙喷泉 -> 东门
        - **五龙喷泉:** (广场西北角)
            - **表演时间:** 整点启动15分钟 (09:00 - 17:00)
        - **备注:** 南门进东门出

#### 下午
- **项目类型:** 景点, 美食
- **目的地:** 济南
- **事项:**
    - **泉城广场:**
        - **开放时间:** 免费
        - **活动:** 广场西侧常有鸽子群，可买粮食(3元/包)投喂
        - **喷泉表演:** 10:00, 15:00, 20:00 三场喷泉，每场持续约20分钟
    - **珍珠泉:**
        - **开放时间:** 全天开放
        - **门票:** 免费
        - **定位:** 济南历下区院前街1号 (省人大院内)
    - **曲水亭街:**
        - **开放时间:** 免费
        - **活动:** 街上走一走，墙上有大学的可以拍照
        - **美食推荐:**
            1. 老周家 牛肉烧饼
            2. 刘小忙把子肉
    - **千佛山:**
        - **开放时间:** 门票 30元/人，免费入园时间5点-6点半和18点-22点半
        - **活动:** 从南门上山，10-20分钟能登顶

### 10月6日 (周五)

#### 上午
- **项目类型:** 出发, 行李寄存, 景点
- **目的地:** 淄博
- **事项:**
    - **交通:** 济南 -> 淄博, D6071次列车 (08:50 - 09:32)
    - **行李寄存:**
        - **寄存柜:** 支持24小时自助存取
            - **中号柜:** 可容纳20寸行李箱，3小时8元/柜，不足3小时按3小时计费，超出按4元/小时叠加
            - **大号柜:** 3小时10元/柜，超出按5元/小时叠加
        - **方案1:** 淄博站寄存柜
        - **方案2:** 门口小超市寄存 (12元/包/天)
    - **淄博陶瓷琉璃博物馆:**
        - **开放时间:** 09:00 - 17:00
        - **门票:** 免费，但要提前7天预约 (9.30)，约9-12点的
        - **游玩线路:** 4楼『琉璃灯工厅』→『五色厅』→3楼『国粹厅』→2楼『古瓷厅』
        - **展品亮点:**
            - **4楼五色厅:** 战国时期的琉璃珠【镇馆之宝】
            - **3楼国粹厅:** 有鸡油黄编钟、国宴骆驼、灯工石榴、琉璃做的淄博烧烤
            - **2楼古瓷厅:** 青釉莲花尊【镇馆之宝】
        - **推荐店铺:** 二期二楼东区5602@欣悦家居生活馆 冰箱贴、琉璃摆件和饰品；5505号店小圣诞树8元一个

#### 下午
- **项目类型:** 景点, 美食
- **目的地:** 淄博
- **事项:**
    - **淄博义乌小商品城2期:**
        - **活动:** 买饰品和小礼物
    - **八大局:**
        - **美食广场:** 逛+吃
        - **特色:** 一条南北向的主街+两条东西向的次街 (东一街+东二街)
        - **主街:** 以紫米饼、炒锅饼、文创等面向游客的产品为主
        - **美食推荐:**
            - 🌟白老三炒锅饼，麦香面食紫米饼
            - 🍱博山菜：炸肉和风味茄子
            - 🍢烧烤：走之前再去趟烧烤店

#### 晚上
- **项目类型:** 出发 (至青岛), 景点, 餐饮
- **目的地:** 青岛
- **事项:**
    - **交通:** 淄博 -> 青岛, D8185次列车 (16:41-18:47)，青岛站→汉庭(青岛栈桥火车站东广场店)
    - **餐饮:**
        - **餐厅:** 来之顺海鲜菜馆
        - **推荐:** 海肠捞饭
        - **备注:** 推荐海肠捞饭，美团已买套餐，但是有效期至9.30，到期后需重新买一张
        - **交通:** 来之顺 -> 五四广场，地铁3号线坐6站
    - **五四广场:**
        - **游玩线路:** 溜达一圈之后可以步行至奥帆中心
    - **奥帆中心:**
        - **游玩线路:** 
        - **灯光秀:** 19:30-22:00，导航至奥帆中心海上剧场
    - **石老人海水浴场:**
        - **开放时间:** 09:00-18:00
        - **活动:** 导航至石老人健身区停车场，看好赶海时间，预测是21点之后退潮，提前美团买好送到酒店 (23元/套)

### 10月7日 (周六)

#### 上午
- **项目类型:** 景点
- **目的地:** 青岛
- **事项:**
    - **天主教圣弥厄尔大教堂 (浙江路天主教堂):**
        - **开放时间:** 周一至周六 08:00-18:00, 周日 10:00-18:00
        - **门票:** 10元/人
        - **备注:** 门口拍照即可，不用进去
    - **信号山:**
        - **开放时间:** 06:00-20:00
        - **门票:** 免费，但需要在门口扫描二维码预约
        - **观景楼票价:** 10元/人，可不去
    - **信号山→小麦岛/雕塑园:**
        - **交通:** 3号线转2号线，或者打车12km，20元左右
        - **交通方式:** 地铁转乘或打车
    - **小麦岛:**
        - **门票:** 免费
        - **推荐:** 去小麦岛定位东园北侧更近
        - **游玩线路:** 进去之后直走→到分叉路口(小海豚)左转→进入向上的木栈道→沿着白色石子路走到尽头左转→蓝色房子边上"五棵树"→接着往前走能看到石头墙→再往前就是"孤独的树"
        - **日出:** 天气好的话这个地方可以早看日出，日出时间5点50
    - **雕塑园:**
        - **门票:** 免费
        - **导航:** 雕塑园3号门

#### 下午
- **项目类型:** 景点, 干饭
- **目的地:** 青岛
- **事项:**
    - **小鱼山公园:**
        - **开放时间:** 06:00-20:00
        - **门票:** 免费
        - **游玩线路:** 正门入口 (福山支路) → 沿台阶上山 → 览潮阁 (山顶) → 碧波亭 → 拥翠亭 → 下山
        - **观景特色:** 览潮阁，2楼3楼观景平台无遮挡，可以看到第一海水浴场，也可以远眺栈桥和教堂，与信号山相望，可以看到一片片的红屋顶青岛老房子
    - **栈桥:**
        - **门票:** 免费
        - **活动:** 回澜阁4元 (旺季7:00-19:00, 淡季8:00-17:30)，不用登阁，拍拍照即可
    - **团岛农贸市场:**
        - **活动:** 干饭，海胆/

### 10月8日 (周日)

#### 上午
- **项目类型:** 景点
- **目的地:** 青岛
- **事项:**
    - **汉庭→青海轮渡站:**
        - **交通:** 汉庭（青岛栈桥火车站东广场店）→青海轮渡站，1.8km
        - **交通方式:** 步行或打车
    - **小青岛:**
        - **开放时间:** 06:00-20:00
        - **门票:** 免费
        - **游玩线路:** 海边礁石→堤坝→蘑菇亭→贝壳亭→转角石阶→右边石板路→龙柏树→白色灯塔→小火车轨礁石
        - **备注:** 上岛后往左边开始环岛走一圈
    - **太平山索道:**
        - **开放时间:** 08:30-19:30
        - **门票:** 单程票80元/人
        - **游玩线路:** 湛山寺→太平角公园→中山公园
        - **交通:** 🚗打车到湛山寺南门，大门左边一直走到厕所，旁边有小门可以进去，进到公园可以看到"索道站"
        - **拍照:** 📸湛山寺到太平山拍照最出片！拍照的时候有阿姨会提醒摆动作。在太平山下缆车可以选照片，照片+电子档30元

#### 下午
- **项目类型:** 景点, 返程
- **目的地:** 青岛
- **事项:**
    - **八大关:**
        - **开放时间:** 全天开放
        - **门票:** 免费
        - **游览贴士:** 街区免费开放，部分建筑单独收费 (如花石楼8元，公主楼20元)。花石楼可进入
        - **游玩线路:** 中山公园C出口→韶关路→嘉峪关路→临淮关路（龙柏超适合拍照）→公主楼→蝴蝶楼→花石楼（推荐二楼观景台打卡）
    - **第二海水浴场:**
        - **门票:** 免费
        - **设施:** 冲脚处1元/次，储物柜20元/小时
        - **活动:** 有山洞可以打卡拍照 (随缘逛)

#### 晚上 返程
- **项目类型:** 海上观光, 返程
- **目的地:** 青岛
- **事项:**
    - **青岛轮渡:**
        - **开放时间:** 08:00-18:20，【航行时间】为30min
        - **门票:** 青岛轮渡公众号89元/人，抖音132元/两人 (已买)
        - **环游路线:** 青岛轮渡站→小港湾→邮轮母港→胶州湾大桥→马踏飞燕灯塔→青岛轮渡站
        - **福利:** 凭游船纸质票(核销后领取凭证)可在指定位置领取200毫升啤酒或饮料一杯，及一份鸥食，当日有效
    - **返程:** 青岛北→上海松江，D2911 (18:19-23:34)
