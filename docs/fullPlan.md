# 国庆假期旅行计划

## 整体信息概览
- **目的地:** 济南, 淄博, 青岛
- **旅行时间:** 10月4日 - 10月8日
- **核心活动:** 泉城探访, 淄博美食与文化, 青岛海滨风情

## 详细行程

### 10月4日 (周三)

#### 上午
- **项目类型:** 出发
- **目的地:** 济南西
- **事项:**
    - **交通:** 南通 -> 济南西, G2586次列车, 08:28 - 12:34
    - **票价:** 375元/人
    - **备注:** 3号晚上返回东城，4号预约顺风车从东城前往南通站。

#### 下午
- **项目类型:** 景点, 干饭
- **目的地:** 济南
- **事项:**
    - **交通:** 济南西 -> 你好酒店 (约19公里)
    - **餐饮:**
        - **餐厅:** 陈氏肥蛤（圣凯财富广场店）
        - **备注:** 提前打电话确认，若人多则点外卖或更换餐厅。
    - **黑虎泉:**
        - **开放时间:** 全天开放
        - **门票:** 免费
        - **游玩线路:** 导航至解放阁入口，沿途经过九女泉 -> 白石泉 (可打水) -> 玛瑙泉 -> 黑虎泉。
        - **护城河游船:**
            - **时间:** 09:00 - 17:00
            - **路线:** 黑虎泉 -> 大明湖西, 50元/人
            - **购票:** 微信小程序“天下第一泉”购买，只能购买当天票。上午班次08:00开始预约，下午班次11:00开始预约 (放票时间可能因水位调整)。建议购买16:00班次。
            - **选座建议:** 手机购票最佳位置1、2号，其次是1、2号后面。
    - **大明湖:**
        - **开放时间:** 06:00 - 22:00
        - **活动:** 打卡夏雨荷（还珠格格），在大明湖拍摄夕阳。
    - **超然楼:**
        - **开放时间:** 08:00 - 21:30
        - **门票:** 免费上楼，每晚18:40亮灯，观赏亮灯即可。
        - **拍照机位1:** 搜索“南丰祠新区游船码头”，可拍摄南丰桥与超然楼同框。
        - **拍照机位2:** 搜索“尚泉尚水茶馆”，其前面平台可拍摄湖面与楼阁全景。

### 10月5日 (周四)

#### 上午
- **项目类型:** 景点
- **目的地:** 济南
- **事项:**
    - **交通:** 你好酒店 -> 趵突泉 (约2.5公里)
    - **趵突泉:**
        - **开放时间:** 07:00 - 20:00
        - **门票:** 40元/人 (抖音购票37元/人)
        - **免费入园时间:** 05:00 - 06:30 和 18:00 - 22:30
        - **游玩线路:**
            - **路线1:** 东门 -> 龟石 -> 漱玉泉 -> 李清照纪念堂 -> 李清照蜡像馆 -> 三大殿 -> 趵突泉 -> 万竹园 -> 南门
            - **路线2:** 南门 -> 趵突泉泉眼 -> 漱玉泉 -> 李清照纪念馆 -> 观澜亭 -> 万竹园 -> 北门
        - **五龙喷泉:** (广场西北角)
            - **表演时间:** 整点启动15分钟 (09:00 - 17:00)
    - **曲水亭街:**
        - **特点:** 一条南北向主街 + 两条东西向次街 (东一街、东二街)。
            - **主街:** 以紫米饼、炒锅饼、文创等游客产品为主。
            - **东一街:** 本地居民常去的菜市场和早餐店。
            - **东二街:** 商业化，主要面向游客。

#### 下午
- **项目类型:** 景点, 美食广场
- **目的地:** 济南
- **事项:**
    - **五龙潭公园:**
        - **开放时间:** 全天开放
        - **门票:** 30元/人 (免费入园时间: 05:00 - 06:30 和 18:00 - 22:30)
        - **游玩线路:** 南门 -> 五龙壁 -> 天镜泉 -> 玉泉 -> 月牙泉 -> 美铭广场 -> 邓恩铭塑像 -> 假山机位 -> 五龙喷泉 -> 东门
        - **备注:** 建议南门进东门出。
    - **珍珠泉:**
        - **定位:** 济南历下区院前街1号 (省人大院内)
        - **喷泉表演:** 10:00, 15:00, 20:00 共三场，每场约20分钟。
    - **美食广场:** 逛 + 吃。

### 10月6日 (周五)

#### 上午
- **项目类型:** 出发, 行李寄存, 景点
- **目的地:** 淄博
- **事项:**
    - **交通:** 济南 -> 淄博, D6071次列车 (08:50 - 09:32)
    - **行李寄存:**
        - **方案1:** 淄博站寄存柜。
        - **方案2:** 车站门口小超市寄存 (12元/包/天)。
        - **方案3:** 淄博站站外负一层出租车上客点B有行李寄存点。
        - **取行李:** 进站前先去地下一层取行李，再乘坐电梯或扶梯上至地上进站口。
        - **寄存柜费用 (通用参考):**
            - 中号柜 (可容纳20寸行李箱): 3小时8元，超3小时按4元/小时叠加。
            - 大号柜:
                - 方案一: 20元/8小时，超8小时按4元/小时叠加。
                - 方案二: 3小时10元，超3小时按5元/小时叠加。
    - **淄博陶瓷琉璃博物馆:**
        - **门票:** 免费，需提前7天预约 (例如9月30日预约)，预约9:00-12:00时段。
        - **游玩线路:** 4楼『琉璃灯工厅』→『五色厅』→3楼『国粹厅』→2楼『古瓷厅』
        - **展品亮点:**
            - **4楼:** 浴火芳华—淄博琉璃灯工艺术展, 五色厅 (展出战国时期琉璃珠，镇馆之宝)。
            - **3楼:** 国粹厅 (展出鸡油黄编钟、国宴骆驼、灯工石榴、琉璃烧烤)。
            - **2楼:** 古瓷厅 (展出青釉莲花尊，镇馆之宝)。

#### 下午

- **目的地:** 淄博
- **事项:**
    - **干饭:**
        - **美食推荐:** 🌟白老三炒锅饼, 🍱 博山菜 (炸肉、风味茄子), 🍢 烧烤 (离开前再去吃一次)。
